# GooWatch

Movies, series and anime in one app (Windows + Android), with **Extensions**.

- **Extensions** use the Stremio add-on format: paste the address of any compatible extension in *Settings → Extensions*
  to get its catalogs, streams and subtitles. Cinemeta (movies & series) and Kitsu (anime) come built in.
- Open-directory / FTP servers can still be added as sources (*Settings → Sources*).
- One powerful player on the phone (libVLC): plays practically every file, audio-track picker, subtitles with automatic online search.
- Auto-update from GitHub Releases (Windows installer and Android APK).

Releases: every push to `main` builds `GooWatch-Setup-<version>.exe` and `GooWatch-<version>.apk` (see `.github/workflows/release.yml`).
